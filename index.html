rclone

Personal Google Drive Backup

This OAuth application is operated by lorinlee solely to use rclone for backing up personal files from an owner-controlled computer to the owner's Google Drive.

How it works

rclone runs on the owner's computer. After the owner authorizes access with Google, rclone transfers selected backup files directly to Google Drive. This website is informational only and does not process backup files or OAuth credentials.

Google Drive permissions

The application requests the Google Drive scope to list, read, create, update, and delete files as needed for the owner's configured backup tasks. This is a personal tool, not a public backup service.
