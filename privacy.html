Privacy Policy

Effective date: 9 November 2026

This policy describes the personal rclone Google Drive OAuth application operated by lorinlee.

Purpose and data use

The application is used only by its owner to back up personal files from an owner-controlled computer to the owner's Google Drive. rclone may access file contents, file names, folder structure, identifiers, sizes, timestamps, and other metadata required to perform and verify configured backup operations.

Storage and sharing

Backup files are stored on the owner's devices and in the owner's Google Drive. OAuth credentials and tokens are retained on the owner's devices for authentication. They are not published to this website or its source repository. This application does not sell Google user data, use it for advertising, share it with unrelated third parties, or use it to train AI models.

Retention and control

The owner controls backup retention and can delete local or Drive copies. Access can be revoked at any time through Google Account third-party connections. Revoking access prevents future access but does not automatically delete existing backups.

Website hosting

This informational website does not collect backup files, request Google sign-in, or include analytics, tracking scripts, or application cookies. GitHub Pages hosts the website and may process standard request information according to GitHub's privacy statement.

Google API data

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact the operator through lorinlee on GitHub.
